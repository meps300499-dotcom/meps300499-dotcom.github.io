# Privacy Policy for yt-agents

Last updated: October 20, 2026

yt-agents is a personal automation tool operated by the owner of a single YouTube channel. It is not offered to the public and is used only by its owner.

## What data the app accesses

With the owner's consent through Google OAuth, the app uses the YouTube Data API and the YouTube Analytics API to upload videos to the owner's own channel, set video metadata and thumbnails, and read the channel's own statistics (views, watch time, subscribers) for weekly performance reports.

## How data is used and stored

Data is used only to publish the owner's videos and to produce reports for the owner. The OAuth refresh token is stored as an encrypted secret in the owner's private GitHub repository. Channel statistics are summarized in the owner's private repository. No data is sold, shared with third parties, or used for advertising.

## YouTube and Google

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms). See the Google Privacy Policy (https://policies.google.com/privacy).

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. After revocation the app can no longer access the channel.

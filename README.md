# yt-agents

yt-agents is a personal automation tool used by the owner of a single YouTube channel. It prepares educational videos and uploads them to the owner's own channel through the official YouTube Data API, and reads the channel's own statistics through the YouTube Analytics API for weekly reports.

The tool is not offered to the public and does not access any other user's account.
